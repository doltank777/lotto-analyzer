Lotto Analyzer 1.3.0
====================

1. 프로그램 소개
----------------
Lotto Analyzer는 저장된 과거 로또 당첨 데이터를 다양한 통계 관점으로 분석하고,
분석 결과를 기반으로 추천번호를 생성하는 Windows용 프로그램입니다.

본 프로그램은 단순 랜덤 번호 생성기가 아니며, 과거 당첨 데이터의 출현빈도,
최근 추세, Pair/Triple 조합, 패턴, 장기 미출현 정보 등을 종합적으로 활용합니다.

본 프로그램에서 제공하는 추천번호는 과거 데이터 기반 통계 분석 결과이며,
로또 당첨을 보장하지 않습니다.


2. 주요 기능
------------
- 과거 데이터 기반 추천번호 5세트 생성
- 출현빈도 / 최근 HOT·COLD / 추세 분석
- Pair / Triple 조합 분석
- 홀짝 / 고저 / 번호합 / 연속번호 패턴 분석
- 최근 회차 기준 백테스트
- 저장된 당첨번호 회차조회
- 신규 당첨 데이터 직접 등록
- 추천 설정 저장 및 기본값 복원
- 추천번호 PNG / PDF / TXT 내보내기
- 프로그램 및 실행환경 정보 확인
- 시스템로그 조회 및 저장


3. 실행 방법
------------
Lotto Analyzer.exe를 실행합니다.

프로그램과 함께 제공되는 database 및 config 폴더는
삭제하거나 이동하지 않는 것을 권장합니다.

프로그램 실행에 lotto_numbers.xlsx 파일은 필요하지 않습니다.


4. 배포 폴더 구조
----------------
Lotto Analyzer 1.3.0/
├── Lotto Analyzer.exe
├── database/
│   └── lotto.db
├── config/
│   └── recommendation_settings.json
├── README.txt
└── LICENSE.txt

Lotto Analyzer.exe와 database, config 폴더의 상대적인 위치를
변경하지 않는 것을 권장합니다.


5. 데이터베이스
--------------
database/lotto.db 파일에 로또 당첨번호 데이터가 저장됩니다.

프로그램은 EXE 파일이 위치한 디렉터리를 기준으로
database 폴더의 lotto.db 파일을 사용합니다.

프로그램의 회차조회, 통계분석, 추천번호 생성 및 백테스트는
이 데이터베이스에 저장된 당첨 데이터를 기준으로 동작합니다.

database/lotto.db 파일을 임의로 삭제하거나 수정하면
저장된 당첨 데이터가 손상될 수 있으므로 주의하시기 바랍니다.


6. 신규 당첨 데이터 등록
------------------------
새로운 로또 당첨 회차가 발표되면 프로그램의
"당첨 데이터" 메뉴에서 직접 신규 회차를 등록할 수 있습니다.

당첨 데이터 화면에서는 다음 정보를 확인할 수 있습니다.

- 현재 데이터베이스에 저장된 최신 회차
- 다음 등록 예정 회차

다음 등록 예정 회차는 현재 최신 회차 + 1을 기준으로
자동 입력됩니다.


[등록 방법]

1) Lotto Analyzer를 실행합니다.

2) 왼쪽 메뉴에서 "당첨 데이터"를 선택합니다.

3) 현재 저장 최신 회차와 다음 등록 회차를 확인합니다.

4) 등록할 회차를 확인합니다.

5) 해당 회차의 일반 당첨번호 6개를 입력합니다.

6) 보너스번호 1개를 입력합니다.

7) "당첨 데이터 등록" 버튼을 누릅니다.

8) 등록 확인창에 표시되는 회차, 당첨번호,
   보너스번호를 다시 확인합니다.

9) 내용이 정확하면 등록을 진행합니다.

10) 등록 완료 메시지와 변경된 최신 회차를 확인합니다.


[입력 규칙]

- 회차는 1 이상의 숫자여야 합니다.
- 일반 당첨번호는 정확히 6개를 입력해야 합니다.
- 모든 번호는 1~45 범위여야 합니다.
- 일반 당첨번호 6개는 서로 중복될 수 없습니다.
- 보너스번호는 일반 당첨번호와 중복될 수 없습니다.
- 이미 저장되어 있는 회차는 다시 등록할 수 없습니다.


[중요]

당첨 데이터 등록 전 실제 공식 당첨 결과와
입력한 번호가 일치하는지 반드시 확인하시기 바랍니다.

등록된 기존 회차는 당첨 데이터 화면에서 수정하거나
덮어쓸 수 없습니다.

신규 회차가 등록되면 lotto.db에 저장되며,
이후 회차조회 및 각종 분석 기능에서 해당 데이터가 사용됩니다.


7. 당첨 데이터 관리 방식
------------------------
배포 버전에서는 lotto_numbers.xlsx 파일을 사용하지 않습니다.

프로그램에서 새로운 회차를 추가할 때는
"당첨 데이터" 메뉴를 이용합니다.

신규 데이터는 다음 구조로 저장됩니다.

당첨 데이터 화면
        ↓
입력값 검증
        ↓
신규 회차 확인
        ↓
database/lotto.db 저장

프로그램을 종료한 후 다시 실행해도
등록된 당첨 데이터는 lotto.db에 유지됩니다.


8. 회차조회
-----------
"회차조회" 메뉴에서 데이터베이스에 저장된 특정 회차의
당첨번호 6개와 보너스번호를 확인할 수 있습니다.

신규 회차를 직접 등록한 경우 회차조회를 통해
등록 결과를 확인하는 것을 권장합니다.


9. 통계분석
-----------
"통계분석" 메뉴에서는 저장된 과거 당첨 데이터를 기준으로
다양한 통계 결과를 확인할 수 있습니다.

주요 분석 항목은 다음과 같습니다.

- 번호별 출현빈도
- 최근 HOT / COLD 번호
- 번호별 추세
- Pair 조합
- Triple 조합
- 장기 미출현 번호
- 홀짝 패턴
- 고저 패턴
- 번호합 패턴
- 연속번호 패턴

신규 당첨 데이터를 등록하면 이후 통계분석 실행 시
해당 회차가 포함된 데이터가 분석에 사용됩니다.


10. 추천번호
------------
"추천번호" 메뉴에서는 저장된 과거 당첨 데이터를
종합 분석하여 추천번호 5세트를 생성합니다.

추천번호 생성에는 출현빈도, 최근 출현빈도, 추세,
장기 미출현 정보, Pair/Triple 조합 및 각종 패턴 등이
종합적으로 활용됩니다.

생성된 추천번호는 PNG, PDF, TXT 형식으로
내보낼 수 있습니다.


11. 백테스트
------------
"백테스트" 메뉴에서는 과거 회차를 기준으로
추천번호 생성 방식을 검증할 수 있습니다.

백테스트는 추천번호 생성 로직의 과거 데이터 기준 결과를
확인하기 위한 기능이며 미래 당첨 결과를 의미하지 않습니다.


12. 추천 설정
-------------
config/recommendation_settings.json 파일에
추천번호 생성 설정이 저장됩니다.

"추천 설정" 화면에서 각 설정값을 변경할 수 있으며,
필요한 경우 기본값으로 복원할 수 있습니다.

설정을 변경한 경우 프로그램을 다시 실행해도
저장된 설정값이 유지됩니다.


13. 시스템로그
--------------
"시스템로그" 메뉴에서는 프로그램 실행 중 발생한
주요 처리 내역을 확인할 수 있습니다.

추천번호 생성, 통계분석, 백테스트,
당첨 데이터 등록 등의 처리 상태를 확인하는 데 사용할 수 있습니다.


14. 데이터 백업
---------------
당첨 데이터를 직접 등록하여 계속 사용하는 경우
database/lotto.db 파일을 주기적으로 백업하는 것을 권장합니다.

백업 방법은 프로그램을 종료한 상태에서

database/lotto.db

파일을 다른 폴더에 복사해 두면 됩니다.

데이터베이스에 문제가 발생한 경우 보관해 둔 lotto.db 파일을
기존 database 폴더에 다시 복사하여 복구할 수 있습니다.

DB 파일을 복사하거나 교체할 때는 Lotto Analyzer를
먼저 종료하는 것을 권장합니다.


15. 주의사항
------------
본 프로그램은 과거 당첨 데이터 기반 통계 분석 결과를 제공하며,
로또 당첨을 보장하지 않습니다.

추천번호는 참고용으로 사용하시기 바랍니다.

당첨번호를 직접 등록할 때는 회차, 일반 당첨번호 6개,
보너스번호가 실제 당첨 결과와 일치하는지 반드시 확인하시기 바랍니다.

database/lotto.db 및
config/recommendation_settings.json 파일을
임의로 삭제하지 않는 것을 권장합니다.
