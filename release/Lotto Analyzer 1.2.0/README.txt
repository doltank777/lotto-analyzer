Lotto Analyzer 1.2.0
====================

1. 프로그램 소개
----------------
Lotto Analyzer는 저장된 과거 로또 당첨 데이터를 다양한 통계 관점으로 분석하고,
분석 결과를 기반으로 추천번호를 생성하는 Windows용 프로그램입니다.

본 프로그램은 단순 랜덤 번호 생성기가 아니며, 과거 당첨 데이터의 출현빈도,
최근 추세, Pair/Triple 조합, 패턴, 장기 미출현 정보 등을 종합적으로 활용합니다.

2. 주요 기능
------------
- 과거 데이터 기반 추천번호 5세트 생성
- 출현빈도 / 최근 HOT·COLD / 추세 분석
- Pair / Triple 조합 분석
- 홀짝 / 고저 / 번호합 / 연속번호 패턴 분석
- 최근 회차 기준 백테스트
- 저장된 당첨번호 회차조회
- 추천 설정 저장 및 기본값 복원
- 추천번호 PNG / PDF / TXT 내보내기
- 프로그램 및 실행환경 정보 확인
- 시스템로그 조회 및 저장

3. 실행 방법
------------
Lotto Analyzer.exe를 실행합니다.

프로그램과 함께 제공되는 database 및 config 폴더는 삭제하거나 이동하지 않는 것을 권장합니다.

4. 배포 폴더 구조
----------------
Lotto Analyzer 1.2.0/
├── Lotto Analyzer.exe
├── database/
│   └── lotto.db
├── config/
│   └── recommendation_settings.json
├── README.txt
└── LICENSE.txt

5. 데이터베이스
--------------
database/lotto.db 파일에 과거 당첨번호 데이터가 저장됩니다.

프로그램은 EXE 파일이 위치한 디렉터리를 기준으로 database 폴더를 찾습니다.

6. 추천 설정
------------
config/recommendation_settings.json 파일에 추천번호 생성 설정이 저장됩니다.
추천 설정 화면에서 값을 변경하거나 기본값으로 복원할 수 있습니다.

7. 주의사항
-----------
본 프로그램은 과거 당첨 데이터 기반 통계 분석 결과를 제공하며,
로또 당첨을 보장하지 않습니다.

추천번호는 참고용으로 사용하시기 바랍니다.
